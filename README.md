# Pokemon Explorer

A modern, interactive web application designed to search Pokemons by their type, name or id. 
<img width="1895" height="926" alt="image" src="https://github.com/user-attachments/assets/40aba349-723a-4df6-bd4d-3f335228a32a" />


##  Key Features
**Searching Pokemons** You can search Pokemons by their name,id or type
**Pokemon Info** By clicking on a pokemon you can check their stats, other appearances and many more

## Tech Stack
 React.js, TailwindCSS, @tanstack/react-query, TypeScript


##  How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/kkubacki04/projektpiwo.git](https://github.com/kkubacki04/projektpiwo.git)
   
2. **Install dependencies:**

    ```bash
    npm install


3. **Start the development server:**

    ```bash
    npm start
